# Shared Category Photographs and Global Appearance — 11 October 2026

## Owner-requested correction
Technical Control's category management list formerly rendered flat cards with generic placeholder image symbols because only the Client app carried bundled category photographs. The two Flutter executables could not see one another's asset bundle, and the Technical UI only checked database upload paths.

## Correct implementation
- **Single tracked photo source:** physically moved all 23 existing `category_*.webp` assets and the separate real `services_public_photo.jpg` from `apps/wantok_app/assets/images` to `packages/wantok_ui/assets/images`. There are no duplicated photo files per category in source control.
- **Shared Flutter asset registration:** `packages/wantok_ui/pubspec.yaml` publishes category and reference images. Both apps depend on `wantok_ui` and resolve `packages/wantok_ui/assets/images/...`.
- **Single supported image lookup:** `WantokCategoryMedia.assets` maps original category slugs to their unique photographs and is consumed by Technical Control. The Client continues using the original `WantokCategoryStyles` styles and now points to the same package assets. The existing backend category identity, names, booking modes and media paths are unchanged. Tests compare visual identity and ensure that category photos aren't reused across slugs.
- **Image precedence:** published `WantokBrandingScope` media override (Home image then card image), category `image_path` stored in the existing branding storage, and finally the shared bundled photograph. If a **new inactive draft has never received a photo**, the editor displays an upload-needed placeholder; it does not borrow another category's photo.
- **Global theme:** Technical Control now reads published `wantok_branding_state` and uses `WantokBrandingTheme` for the entire Technical application, including navigation routes, primary/accent colours and card radius, rather than configuring a separate isolated theme. The category page uses theme-derived card colours, global green engineering header, readable summary metrics, status chips and responsive layouts.
- **Safety:** no images were generated, edited, re-licensed or duplicated; this correction strictly transfers already approved photographic assets. Papua New Guinean/Pacific authenticity reviews for six previously added draft categories remain outstanding, and those categories remain inactive.
