## Technical Control → Service categories
Authenticated **Technical Platform Administrators** get a new sidebar and toolbar entry on Technical Control (`http://127.0.0.1:3100/`). Backend RPCs independently verify admin permission. The panel supports:
- List/filter all active and inactive categories, sort orders, booking modes, Home/Services placement.
- Add inactive categories and edit names, descriptions, vertical, booking mode, sort order and visibility.
- Upload/replace individual JPEG, PNG or WebP pictures (3 MB maximum); reject arbitrary external URLs and images uploaded under another slug.
- Archive an existing category without destroying provider/bookings data.
- Delete only an **inactive, unused** draft; the server rejects deletion when provider listings, booking records or category interest references exist.
- Every write has an audit entry, with optimistic updated-at protection against stale edits. Category slugs are immutable after creation to preserve media and provider links.

## Safety and image quality
The six new categories stay **inactive** until individually reviewed. For any photograph containing people, select realistic imagery specifically appropriate to **Papua New Guinea and the wider Pacific**; avoid presenting generic regional stock models as real PNG people or official agencies. Use **distinct, category-appropriate** media, no reused photograph. User-uploaded images must respect photographer licences, model consent and the public-service no-endorsement rule.

The AI generation attempt in this pass produced a combined application mock-up rather than six usable image assets. It was rejected and was not inserted, duplicated or published. Image creation/approval for these six categories remains a separate visual deliverable, which must not be confused with the **functioning category editor**.
